# 🎓 Student Placement Predictor

A machine learning desktop app that predicts whether a student is likely to be **Placed** or **Not Placed** based on their academic and skill profile.

## ✨ Features

- Predicts placement from 6 inputs: CGPA, Backlogs, Communication Rating, Projects, Internships and Technical Skills
- Simple Tkinter GUI with a clear PLACED / NOT PLACED result
- Reset button to clear the form
- Batch prediction: load a CSV file to predict for many students at once

## 🛠️ Tech Stack

- Python
- Scikit-learn (Random Forest)
- Pandas, NumPy
- Tkinter (GUI)
